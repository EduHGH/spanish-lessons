2Mapa del módulo Module map8′

hacer · tú→ afirmativohaz
decir · tú→ afirmativodi
comer · tú→ negativono comas
dar + me + lo→ junto al verbodámelo
le + lo→ pronombresse lo doy
1. Imperativo afirmativo: tú como «él»; usted -e / -a; vosotros -d; irregulares de tú: di, haz, ve, pon, sal, sé, ten, ven.
2. Imperativo negativo: no + subjuntivo (no comas, no hagas).
3. Pronombres: detrás en afirmativo (dame, tráigame), delante en negativo (no me llames).
4. Combinados: persona + cosa (me lo, te la); le / les + lo = se lo.
5. Relativos: que, donde, quien, el que / la que.

4Retos mezclados Mixed challenges8′

Ordena y decide verdadero o falso. Order and decide true or false.

  1. «No trabajas» es un imperativo negativo correcto. {Falso|Verdadero}
  2. En afirmativo, el pronombre va detrás del verbo. {Verdadero|Falso}
  3. Le + lo se convierte en «se lo». {Verdadero|Falso}
  4. «Donde» se usa para lugares. {Verdadero|Falso}
  5. «Haz» es el imperativo de «hacer» para tú. {Verdadero|Falso}
  6. «Ve» es el imperativo de «ir» para tú. {Verdadero|Falso}
  7. En negativo, el pronombre va detrás del verbo. {Falso|Verdadero}
  8. «No comas» es imperativo negativo de «comer». {Verdadero|Falso}
  9. «Quien» se refiere a personas. {Verdadero|Falso}
  10. «Dámelo» lleva dos pronombres. {Verdadero|Falso}
  11. Para vosotros, el imperativo afirmativo termina en -d. {Verdadero|Falso}
  12. «Sal» es el imperativo de «salir» para tú. {Verdadero|Falso}
  13. «No digas» viene de «decir». {Verdadero|Falso}
  14. «Que» es un relativo. {Verdadero|Falso}
  15. «Pon» es el imperativo de «poner». {Verdadero|Falso}
