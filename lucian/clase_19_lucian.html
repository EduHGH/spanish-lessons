How it's made — describing a process with se

Describimos el proceso de inyección de plásticos de principio a fin con el «se» y secuenciadores.

Duración25 min
GramáticaSe pasivo / impersonal
NivelA2/B1
1

El «se» de los procesos

8 min
se calientase + verbo en 3.ª personaEl plástico se calienta a 200 °C.
se inyectanplural si el objeto es pluralSe inyectan las piezas en el molde.
primero, despuéssecuenciadoresPrimero se prepara el material.
por últimocierre del procesoPor último, se saca la pieza.
El «se» describe procesos sin decir quién lo hace. El verbo concuerda con lo que se procesa: «se abre el molde», «se enfrían las piezas».

Para no confundirlos

SE + SINGULAR
  • un objeto: se calienta, se enfría.Se enfría el molde.
  • impersonal: se trabaja, se come.Aquí se trabaja mucho.
SE + PLURAL
  • varios objetos: se inyectan, se sacan.Se sacan las piezas.
  • secuenciadores: primero, después, luego.Luego se limpian los moldes.
Ojo: concuerda con el objeto: «se fabrica una pieza» pero «se fabrican mil piezas», no «se fabrica mil piezas».

🎧 Transcripción del audio

Cómo se fabrica un cubo de plástico

LocutorHoy visitamos una fábrica de objetos plásticos. Ingeniera, ¿cómo se fabrica un cubo?

IngenieraPrimero se prepara el material. Se mezclan los gránulos de plástico con un poco de color.

Locutor¿Y después?

IngenieraDespués se calienta la mezcla hasta que se funde, a unos doscientos grados.

Locutor¿Cómo se forma el cubo?

IngenieraA continuación se inyecta el plástico líquido en un molde de acero.

Locutor¿Se enfría rápido?

IngenieraSí, se enfría con agua durante unos treinta segundos.

Locutor¿Y luego se abre el molde?

IngenieraExacto. Se abre el molde y se saca la pieza.

Locutor¿Qué se hace al final?

IngenieraPor último se revisa la calidad: se mide, se pesa y se rechazan las piezas defectuosas.

📖 Texto de la lectura

Cómo se produce una botella de plástico

La botella de plástico es uno de los objetos más comunes del mundo, pero su producción tiene muchos pasos. Primero se fabrica una pequeña pieza llamada preforma. Para ello se calienta el plástico y se inyecta en un molde.

A continuación, la preforma se calienta de nuevo y se sopla aire dentro. Así se le da la forma final de botella. Después se enfría, se revisa y se cuenta cada pieza.

Por último, las botellas se empaquetan y se envían a las fábricas de bebidas. Allí se llenan, se cierran con un tapón y se colocan las etiquetas. Cuando se terminan de usar, se pueden reciclar y empezar el proceso otra vez.
